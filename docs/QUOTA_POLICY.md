# Reference API quota policy

The Odds API free quota is a scarce enrichment resource. The broad Bet365 discovery feed must not be narrowed merely to save reference credits.

Current policy:
- Bet365/Odds-API.io discovery remains broad.
- The Odds API reference requests remain H2H and scheduled every 12 hours while quota is limited.
- Weak one/two-book reference observations are retained as data but cannot pass the final play gate.
- Additional reference markets (totals, spreads) should be enabled only with explicit quota accounting or a more efficient/reference source.
- Never silently exhaust monthly quota to increase apparent candidate count.
