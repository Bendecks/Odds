# Observation evidence

An odds row is an observation, not a candidate bet. A market with many rows can simply have many selections or alternative lines.

The system therefore uses these terms consistently:
- **observation**: raw bookmaker price/line;
- **reference observation**: independently estimated fair probability for a comparable outcome;
- **scored opportunity**: target price joined to a defensible reference and scored for edge/EV/stake;
- **actionable signal**: scored opportunity that passes the final safety gates;
- **decision**: the single highest-ranked actionable signal, or NO BET.

This distinction prevents high-volume prop markets from appearing attractive merely because they generate many rows.
