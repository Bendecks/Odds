# Reference depth finding

Run 7 produced 57 reference observations across 19 events. Every observation had all five configured reference books, so all 57 were `strong` and final-play-depth eligible.

This is useful negative evidence: retaining one/two-book rows is architecturally correct, but it did not enlarge this particular reference sample because no weak rows existed. The observed bottleneck is coverage/join breadth, not reference-depth filtering.
